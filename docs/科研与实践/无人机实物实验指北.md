# 无人机实物实验指北

## 写在前面

无人机试验，难度高，危险性大，必须小心谨慎，力求“谋定而后动”。

## 一、机械

1. 检查整体机架状态是否横平竖直。
2. 检查螺丝有无缺漏、松动，应一处处检查、一颗颗拧紧。
3. 电机底座螺丝需注意不能拧得太深抵到线圈，否则上电就冒烟。
4. 检查螺旋桨安装是否正确，四旋翼切记相邻螺旋桨不同，对角相同。
5. 检查所有用 3M 胶粘连的硬件设备（NUC、RTK、降压模块、接收机、BB响），安装是否牢固。
6. 在机头朝向附近的机臂上做标记，以方便观察机头朝向。
7. 检查有无电池绑带。
8. 可给底座贴泡沫缓冲，注意空出绑带空间。
9. 检查螺旋桨转动时是否会打线。

## 二、电气

1. 检查所有机载设备供电、通信线路是否完整连通。
	1. 【2026-06-11】
	2. 6S 电池，一头接 BB 响，一个 XT30 公头供电，接一个电流计。电流计多pin的插头接飞控，XT30 公口接一个 XT30 一母分二公，分别接电调、降压模块（输出12V5A） ，降压模块出来给NUC供电。。
	3. 飞控与 NUC 通过 USB 转 TypeC 线连接。
	4. RTK 模块连接在飞控上，注意供电是否足够。
	5. 遥控器接收机连接在飞控上。
	6. 电机通信线从电调出来连接到飞控上（？）
2. 检查电池电量，6S 电池满电约 25.2 V，23 V 以下就应该换电池

## 三、软件

1. QGC 地面站调参。
	1. IMU 较准
	2. 电机转速、方向调试
2. 配置遥控器通道。
3. 悬停油门设置。
4. PID 控制器参数调试。
## 四、实验

1. 起飞前检查锁桨拨杆是否能够锁桨
2. 检查定位数据是否准确
	1. 全方北斗 RTK 不闪红光 ——> 飞控无法提供充足供电，需接电流计。
3. 倘若无法解锁，可以尝试插拔飞控与 NUC 间的连接线（？这究竟是什么问题，能否解决？）
